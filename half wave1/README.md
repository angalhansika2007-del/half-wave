# Half Wave Rectifier Simulation

## Overview
This project demonstrates the design and simulation of a Half Wave Rectifier circuit using Verilog HDL.

A half wave rectifier converts an AC input signal into a pulsating DC output by allowing only one half cycle of the input waveform to pass through.

## Features
- Verilog HDL implementation
- Testbench verification
- Input sine wave simulation
- Output waveform analysis

## Working Principle

During the positive half cycle of the AC input, the diode conducts and produces output.
During the negative half cycle, the diode blocks current and output becomes zero.
